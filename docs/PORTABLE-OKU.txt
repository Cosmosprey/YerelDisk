YerelDisk 1.29.4 — Windows x64 portable package

1. Extract the entire ZIP to a folder.
2. Open YerelDisk.exe.
3. Choose folders and start a scan. The interface is in Turkish.

The package includes Microsoft .NET 10.0.15. No SDK, Visual Studio, PowerShell
command, or separate runtime installation is required. Keep all extracted
files together. Windows 11 x64 is the verified target; the app is unsigned.
Windows may show an unknown-publisher warning. Keep security software enabled.

F6 opens details. CSV and reference files are saved only on request. The app
has no cleanup commands that delete, move, or change scanned files. Experimental
review clues cannot establish that data is unused or safe to delete.

New full scan starts over with the configured locations. Remeasure all uses
the current result's original scope and keeps it visible until replacement.
Folder refresh targets the selected folder, or the open folder without a
selection. At the root it measures the whole scope. The optional 64/128 MiB
in-memory index starts off; it is not a total RAM cap. A full-scope fallback
reports its reason. Mixed-time results identify older and refreshed areas.

The app has no networking, telemetry, accounts, or automatic updates. Normal
scans inspect metadata without reading file contents. Opening a saved reference
reads that selected measurement file. References contain folder paths, sizes,
timestamps, scope and volume identifiers; compression is not encryption.
Optional application record inspection reads limited local HKLM/HKCU Uninstall
values only on request. Including record clues in CSV is a separate opt-in.

Profiles and reference preferences are session-only unless Remember is enabled.
That choice stores local JSON files under LocalApplicationData:
YerelDisk-profiller.json and YerelDisk-referanslar.json. Later relevant dialogs
can reload them. Turning Remember off removes the corresponding preference
file; saved references and CSV files remain separate. Removing a recent entry
does not delete its reference file. No automatic reference-file deletion occurs.

To remove the app, turn off any Remember options if you want to clear those
preferences, close the app, and delete the extracted folder. References, CSV,
clipboard copies and operating-system records remain separate.

Source and measurement limits: https://github.com/Cosmosprey/YerelDisk
Keep LICENSE-YerelDisk.txt and the Lisanslar folder containing .NET licenses
and notices. SHA256 checks integrity; it does not provide a publisher signature.
